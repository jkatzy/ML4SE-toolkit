# Stack v2 Comment Research Archive

This directory preserves the durable comment-syntax research from the Stack v2
language intake. It was restored from repository commit
`9e60ba55b54fbc6571044b8c5e4b4a51c918bd33`. Report content is preserved; only
relocated repository paths and two formatting defects were normalized.

The intake contained 607 exact public Stack v2 labels. At intake, 58 labels
already resolved through the registry and the remaining 549 were assigned across
the eight primary reports below. Six follow-up reports record implementation
confirmation work for 34 disputed or unresolved cases.

These files are historical evidence, not claims about current parser support.
Before changing the registry, revalidate the relevant source links and compare
the recommendation with the current registry, fixtures, and regression tests.
Use the active [research workflow](../README.md) for new work.
